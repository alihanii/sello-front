# Sello Frontend — Next.js (فاز ۱)

بک‌اند: https://github.com/alihanii/sello-back

```bash
npm install
cp .env.example .env.local   # NEXT_PUBLIC_API_URL=http://localhost:8000
npm run dev                  # http://localhost:3000
```

Next.js 15 (App Router) + Tailwind v4، طراحی شیشه‌ای مینیمال با پالت سبز تجاری و خاکستری (ui-ux-pro-max)، RTL با فونت وزیرمتن، حالت روشن/تیره، کاملاً ریسپانسیو (نوار پایین در موبایل)، TanStack Query و به‌روزرسانی زندهٔ عملیات با SSE.

ورود: هر شماره‌ای فروشنده است و شماره‌های `SELLO_ADMIN_PHONES` بک‌اند ادمین؛ در حالت توسعه کد تأیید روی صفحهٔ ورود نمایش داده می‌شود. دیتای دمو ندارد.
